# Project Rules & Clarifications

## Adding and Importing Terms
- Adding terms and importing terms are the same feature.
- There is no manual single-term add form.
- Terms are added by pasting or typing plain text into a text field, which is then parsed into individual terms (e.g. using the format "term - translation (hint)").
- The "Add" action/button triggers the text import screen.
- Editing a single term and deleting a term is still done via the Edit Term screen.
