JohnsonApp допомагає створити власний словник, тренувати слова за допомогою карток і вправ та повторювати їх у момент, розрахований алгоритмом **FSRS-6**. Застосунок не потребує облікового запису або інтернет-з'єднання: словники й прогрес зберігаються локально на пристрої.

## Можливості

- **Окремі мовні сесії** — незалежні словники й прогрес для кожної мовної пари.
- **4 підтримувані мови** — англійська, українська, французька та польська.
- **Словник** — пошук за терміном або перекладом, пагінація, редагування й видалення карток.
- **Статуси навчання** — `Нове`, `Вчу`, `Засвоєно`; статус обчислюється з навчального прогресу.
- **Масовий імпорт** — розбір списку слів, попередній перегляд, звіт про помилкові рядки та відсіювання дублікатів.
- **Флешкартки** — перемішування карток, вибір першої сторони, підказки, навігація та озвучення.
- **Інтервальне повторення** — FSRS-6 планує наступну дату повторення за результатами вправ.
- **4 типи вправ** — вибір відповіді, введення терміна, введення перекладу й аудіювання.
- **Перевірка друкарських помилок** — відповідь з однією помилкою можна вручну зарахувати або відхилити.

Інтерфейс застосунку наразі доступний українською мовою.

## Як працює навчання

1. Застосунок отримує до 100 карток, дата повторення яких уже настала.
2. Користувач обирає розмір поточної сесії; початкове значення — до 10 карток.
3. Для кожного слова створюються вправи:
   - переклад → вибрати правильний термін;
   - переклад → написати термін;
   - термін → написати переклад;
   - прослухати вимову → написати термін.
4. Вправа з варіантами відповіді додається лише тоді, коли в сесії є щонайменше 4 слова.
5. Після завершення всіх вправ для слова результат автоматично перетворюється на оцінку FSRS: `Again`, `Hard`, `Good` або `Easy`.
6. FSRS-6 оновлює складність, стабільність, кількість повторень і дату наступного показу картки.

## Формат імпорту

Одна картка — один рядок. Підказка в дужках є необов'язковою.

```text
apple - яблуко
take off - злітати
bank — банк (фінансова установа)
bonjour – добрий день
```

Підтримуються дефіс із пробілами (` - `), en dash (`–`), em dash (`—`) та кілька інших Unicode-варіантів тире. Unicode-тире може бути без пробілів. Рядки без коректного роздільника потрапляють до списку помилок, а дублікати в межах активної мовної сесії не імпортуються.

## Технології

| Частина | Реалізація |
| --- | --- |
| Мова та UI | Swift, SwiftUI |
| Архітектура | [The Composable Architecture](https://github.com/pointfreeco/swift-composable-architecture) 1.26+ |
| Зберігання | SQLite через [GRDB.swift](https://github.com/groue/GRDB.swift) |
| Планування повторень | Власна реалізація FSRS-6 з 21 стандартним коефіцієнтом |
| Озвучення | `AVSpeechSynthesizer` / BCP-47 локалі |
| Налаштування | `UserDefaults` для ідентифікатора активної сесії |
| Тестування | XCTest, Swift Testing, TCA `TestStore`, in-memory GRDB |

## Структура проєкту

```text
JohnsonApp/
├── App/
│   ├── AppFeature/              # Кореневий reducer і TabView
│   └── JohnsonAppApp.swift      # Точка входу
├── Features/
│   ├── AddTerm/                 # Масове додавання та імпорт
│   ├── CreateSession/           # Створення мовної сесії
│   ├── Dictionary/              # Словник, пошук і фільтри
│   ├── EditTerm/                # Перегляд, редагування та видалення
│   ├── Flashcards/              # Режим флешкарток
│   ├── Learning/                # Налаштування, вправи та підсумок
│   └── Profile/                 # Вибір і керування сесіями
├── Models/                      # Доменні моделі та валідація
├── Services/
│   ├── FSRSClient/              # Планувальник FSRS-6
│   ├── ImportClient/            # Парсер текстового імпорту
│   ├── PersistenceClient/       # GRDB, схема й міграції SQLite
│   ├── SpeechClient/            # Синтез мовлення
│   └── UserDefaultsClient/      # Активна мовна сесія
├── Shared/                      # Спільні UI-компоненти
├── Theme/                       # Кольори та стилі
└── Assets.xcassets/             # Іконка й ілюстрації

JohnsonAppTests/                 # 125 тестових сценаріїв
JohnsonApp.xcodeproj/            # Xcode-проєкт і shared scheme
```



## Приватність і дані

- Дані не надсилаються на зовнішні сервери.
- SQLite-файл `johnson_app.sqlite` створюється у директорії Application Support застосунку.
- Видалення мовної сесії каскадно видаляє її картки та навчальний прогрес.
- Видалення застосунку з пристрою видаляє й локальні дані; резервне копіювання та синхронізація наразі не реалізовані.
